# Abyssian’s Fantasy Mod

A fantasy mod that brings new adventures to Minecraft.

Explore a world of mysterious places, unusual creatures, and magic. The mod is in active development, with more content planned for future updates.

## In-game Field Guide

An in-game field guide helps you discover the mod’s content. Browse its pages for information about creatures, items, crafting, loot, and more.

## Downloads

Download the mod from [CurseForge](https://www.curseforge.com/minecraft/mc-mods/abyssians-fantasy) or the [Releases](https://github.com/Abyssian/abyssians-fantasy-mod/releases) section of this repository.

## Installation

Install Minecraft Forge for the Minecraft version supported by your chosen release, then place the mod’s `.jar` file in your `mods` folder.

Check the release notes for requirements.

## Feedback

Found a bug or have a suggestion? [Open an issue](https://github.com/Abyssian/abyssians-fantasy-mod/issues) with a description.

For bugs, include your Minecraft and mod versions, other installed mods, and a crash report or log if available.
